# 商品选择

用户明确要买、找淘宝同款、补齐单品时才调用 search_products。将公开商品、颜色、材质与风格词组合成 keyword。用户给了预算就传 min_price/max_price（人民币），不要把个人身材数据、姓名、私人衣橱原文或照片地址发给来源服务。

sort 只支持 relevance、popular、price_desc，没有 price_asc。默认相关性；天猫限定只在用户要求时传 tmall_only=true。一页最多五件，不自动调用详情、评论或第二页；工具 schema 是当前参数的唯一依据。

从返回值选择有证据的推荐：
- price_basis=page 是页面参考价，list 是划线价，promotion 是推广参考价；不能称为确定到手价。
- listed_price_in_range=false 表示返回的参考价不在预算内，须说明；来源筛选不保证命中。所有结果超预算时说明没有合适结果，不伪造符合预算的商品。
- 缺失价格、店铺、销量、库存或材质就说明未知，不补造。比较仅限本次结果，不宣称全网最低价，不伪造折扣、返利或推广链接。
- owned=false 表示尚未拥有。商品 ID 不能交给 propose_outfit，也不能自动加入衣橱。

给出少量选择及理由，并保留图片卡片和来源链接。需要结合现有衣服时再读衣橱；购买或试穿始终由用户在应用中明确操作。
