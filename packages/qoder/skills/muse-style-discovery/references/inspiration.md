# 灵感检索

明确风格用 search_inspirations 的 style_id，复用预设风格公共缓存；自定义 keyword 仅写公开风格、服装、场景词。用户要“法式”但具体场景不明时，可先用 get_style_definition 理解风格，结合已有上下文搜索，不必为每个可选条件追问。

一页结果通常足以给第一轮参考。按标题、摘要、标签筛选少量相关内容，说明选择理由；保留作者、原文和图片，不虚构视觉分析或热度排名。不自动翻页，不定时刷新。

只有用户给了笔记链接、选中了某篇，或摘要确实不足时才调用 read_inspiration_note；不要逐篇读全文。无结果时明确说明，用户继续细化需求后再决定是否搜索，不为凑数循环查询。

“照这套给我搭”才进入衣橱流程：把参考拆成配色、廓形和单品类别，再检查真实衣橱，说明可复现部分与缺口。发现缺口不等于用户已决定购买。
