# MUSE 手机与投屏演示

## 两种展示方式

1. **真实手机**：在 Safari 或 Chrome 打开部署后的 HTTPS 地址。自动采用手机全屏布局；不需要原生 App 安装。当前是 Web 原型，没有宣称实现原生或离线 PWA。
2. **电脑投屏**：打开同一地址的 `?present=1`，用手机画布和侧边演示步骤展示。现场可使用屏幕镜像，或者直接投浏览器；不必用 DevTools 假装手机 App。

Sites 默认私有：同一所有者账户可以登录查看。公开给老师/同学免登录访问需要另行设置访问权限，不能把所有者凭据或 bypass token 放进二维码。

## 约三分钟路径

- 发现：打开一个冬季专题，说明它是编辑精选/示例内容，不是实时热度榜。
- 滑动搭配：横滑外套、下装、鞋履；固定下装再换组合，展示固定状态与已有/待购来源。
- 自由画布：拖动衣服改变摆放，保存后从衣橱的「搭配」重新打开，排版仍保留。
- 衣橱：切换衣物、搭配、心愿；点击青色加号，从相册、基础款或链接添加。基础款多选后确认加入。
- 推荐：从「找搭配单品」进入，切换一起搭与相似款；调整预算，放入一件新外套，其他衣服保留。
- 试衣：进入预览并切换候选，明确为示例。Decart 接入位置与素材条件已经保留；未接真实模型时不假称实时换装。
- 保存：保存方案，回到搭配列表；演示标记实际穿过与反馈。
- 刷新：展示本地收藏/方案保留。需要重复时使用“重置演示”，仅清除本应用演示数据。

## 手机现场注意

- 摄像头需要 HTTPS 或 localhost。手机打开电脑的普通 LAN HTTP 地址，通常不能获得摄像头能力；LAN 仅作为不含相机的页面备用演示。
- 默认用预置服装与示例图跑主流程，保证网络短暂变化时仍可展示页面；这不等于应用已实现离线缓存。
- 原型数据按浏览器保存，电脑和手机不自动同步。可以独立重置后执行相同路径，真实多设备同步留给账号与后端。
- 本次不需要支付、不需要老师提供账号数据、不需填入任何平台 API Key。

本地启动：`npm run dev -- --host 0.0.0.0`。部署版优先用于相机与手机演示。

直达搭配工作台：在地址后加 `?screen=outfit`。首访会提供三套明确标注「示例」的搭配；不会覆盖已有本地记录。当前浏览器缓存使用 `muse-mobile-v1`，仅用于此原型。
