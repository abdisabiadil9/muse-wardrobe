# Lenso 改版验收记录

日期：2026-11-16。现有 MUSE 项目改造，未覆盖已有本地存储，也未修改 sibling fitting-studio。

## 已实际验证

- TypeScript + Vite 生产构建通过；`git diff --check` 通过。
- 390 × 844 和 360 × 780 浏览器视口：首页整套服装、选衣与试穿入口在首屏可见，底部导航正常。
- 单件替换：点针织衫 → Lenso Sheet 的上装分类 → 选另一件 → 自动回首页，其他单品保留。
- 整套草稿：选不同外套后关闭，首页原外套保留；重新选择并应用，首页正确变更。
- 点击“就穿这套”后刷新，已选衣服和已记下状态保留。
- 新底部导航可以进入衣橱，再返回今日。
- 生产构建通过 4179 端口临时预览，确认 StyleX CSS、玻璃导航和 Sheet 均渲染；生产版单件替换生效。
- 1280 × 900 桌面预览：手机框和演示说明正常，Sheet 在视口中央完整显示。它是原生顶层弹层，桌面不强行裁进手机框。
- 开发版和生产版捕获的控制台均无 error/warn。
- manifest、图标 HTTP 200；本机直连当前网络地址 `100.83.225.53:5179` 返回 200。尚未用实体手机访问。
- Qoder 协议参考的 8 项离线测试通过；不等于云端联调成功。
