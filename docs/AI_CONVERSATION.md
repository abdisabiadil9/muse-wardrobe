# AI 对话与搭配内容流

本次扩展基于现有衣橱、任务、Qoder Session 和 Seedream 接入。没有修改 Agent 定义、工具执行循环、Memory/Dream 或接入 skill。

## 使用链路

- 五个主入口：今日、衣橱、居中的 AI 搭配、灵感、我的。
- AI 助手名为 **Lumi**，应用名仍为 MUSE。右上角支持新建对话与历史切换；历史按最近活动排序，并保留当前对话。
- 灵感是编辑精选的风格参考；可以筛选、收藏，点击「用这个灵感搭配」填入对话框，由用户发送。
- AI 对话展示原生公开消息、工具调用及结果、最终回答、搭配卡片。卡片打开详情；「用这套」明确采纳并保存，「调整这套」进入现有编辑器，「生成上身图」进入人物选择与生成确认。
- 首页展示 AI 提案；我的展示保存搭配、生成预览及收藏。浏览提案不改变草稿，生成图片仍需用户主动操作。
- Seedream 整套结果仅在单品 ID 和资源 ID 全部一致时用于对应提案封面和对话卡片。单件结果单独注明，不冒充整套效果。改变搭配不会改写旧任务的图片归属。

## 原生事件读取

已有 Worker 将 Qoder 完整事件写入 `agent_events`。新增唯一的后端能力是受现有登录鉴权保护的只读接口：

```http
GET /api/v1/tasks/{taskId}/agent-events?after=evt_...&limit=100
```

返回 `{ data: NativeEvent[], next_cursor: string | null }`。保留原生 `id`、`type`、`custom_tool_use_id`、`tool_use_id` 等字段，不创建另一套服务端消息协议。接口校验任务及 Session 归属，过滤思考事件、凭据和内部记忆读取内容，不调用供应商。

游标代表最后扫描的事件，包含被过滤事件。前端跟随变化的游标分页，直到游标不再前进；不能根据返回数组长度判断是否结束。前端活动期间约每 1.2 秒读取新事件，页面恢复时补读；现有业务任务 SSE/状态机制保持兼容。

当前 Worker 订阅的是 Qoder **buffered 完整事件**，没有开启 `event_deltas`。因此前端按片段更新：相同原生 ID 替换快照、不同 ID 追加，不将完整文本重复拼接，不模拟打字。未来启用增量协议时必须另加 delta 适配与测试。

## 前端状态规则

- 按原生结构分类，不根据正文里的 Thought/Action 等词分类。工具结果关联到原调用位置，公开文本按到达顺序保留；`session.status_idle/end_turn` 才标记最终回答。
- 工具展开状态用任务 ID + 调用事件 ID 保存于组件状态，工具完成不自动折叠。上滑阅读停止跟随，点击「回到最新消息」恢复跟随。
- Markdown 不执行 HTML；图片只显示本应用受保护的媒体地址或当前衣橱/试穿结果中已知的图片地址。上身图和搭配卡片均可直接在对话中展示。
- 未知提交保留原幂等键；刷新、恢复读取和切换页面不提交新任务。现有 `needs_input` 使用原补答接口；完成后的新提问创建新的搭配任务，并在现有 message 长度限制内带入必要的最近上下文。
- 不同场景草稿继续独立。旧提案要重新使用时，用户明确点击后按当前版本和锁定条件再次校验；不能以晚到结果覆盖新选择。

- 每段对话独立维护任务、上下文、提交幂等键和错误。切换期间到达的结果只写回原对话；后台继续收集其他对话的搭配卡片。新建、切换和刷新不会触发模型调用。
- 本机旧 `conversation:v1` 记录首次打开时迁移到 `conversation:v2` 的历史对话，原记录不删除。新建对话不携带其他对话的最近上下文；显式确认的长期偏好仍按已有 Memory 机制工作。
- 自由画布在 API 边界补齐 `z_index` 图层顺序，兼容缺少该字段的旧本机草稿；衣物与坐标不变。测试使用真实 OpenAPI 校验和 PostgreSQL 保存，避免仅靠宽松 mock 掩盖格式错误。

## 存储边界

任务、事件、保存搭配、图片仍存储在现有后端。为保持本次后端改动最小，对话任务索引、卡片关联、收藏和当前查看位置存于按用户隔离的本机浏览器存储；不声称它们已跨设备同步。清理浏览器/WebView 数据会清除这些本机索引，服务器已保存的搭配仍可读取。不可访问或已删除的任务/媒体会从内容卡片中移除。

APK 是现有网页的演示壳，访问此电脑服务即可加载更新，无需仅为网页改动重打 APK。实体手机的键盘、热点及 WebView 行为仍应单独验收。

## 验证

```sh
npm run test:db  # 隔离 PostgreSQL 权限、恢复、原生事件分页与裁剪测试
npm run build
npm run test:ui  # 先启动开发页面；使用独立 Chrome，全部 /api 请求由测试拦截
```

`test:ui` 不调用 Qoder 或 Seedream。它验证原生消息/工具更新、展开状态、Markdown 图片、阅读位置、刷新不重发、显式采纳、首页卡片、试穿结果、我的与灵感预填，以及新建/切换/刷新历史、上下文隔离、320–430px 手机布局和缩短视口下输入框可用性。测试生成图使用明确的本地 fixture，不能作为真实模型效果证明。真实供应商验证与当前未验收项记录于 [VALIDATION.md](VALIDATION.md)。
