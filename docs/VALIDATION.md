使用独立测试浏览器的 Chrome 手机仿真（390 × 844），没有读取用户浏览器账号或密码。

- AI 返回之前及返回之后未采纳时，草稿版本不变。
- 点击“用这套搭配”更新首页；保留自由换衣。
- 单件人物照片上传、明确生成成功；刷新只恢复原任务，没有创建额外图片任务。
- 完成后可以切换原图、保存试穿图；无页面脚本错误、无横向页面溢出。
- 通过电脑局域网 IP 的 HTTP 页面访问成功；已确认该环境没有 SubtleCrypto 且页面无溢出。文件上传的摘要回退路径另有自动测试。
- 刷新后恢复单件/整套和目标衣物选择；仍需用户重新确认照片使用授权。
- 自动化曾遇到弹层关闭动画后的立即点击未导航；等待关闭后正常进入，不计为模型失败。
